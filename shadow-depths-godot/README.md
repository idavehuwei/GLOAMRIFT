# 烬下 · Below the Embers — 0.10 开始界面与存档槽

Godot 4 暗黑风格斜俯视 3D 动作冒险原型。正交相机、实时灯光阴影、精细像素渲染。美术和面板参考经典暗黑 ARPG，所有模型、贴图和图标为程序生成的原创内容。

## 启动

用 Godot 4.3+ 导入 `project.godot`，按 F5。已在 macOS Godot 4.7 实际运行验证，无需第三方插件或素材下载。

```sh
/Applications/Godot.app/Contents/MacOS/Godot --path /Users/weihu/AI/ShadowDepths/shadow-depths-godot
```

新游戏先选职业，然后进入第一章安全城镇。与鸦邮差交谈领取委托，补给后从东侧城门出发。

## 操作

| 按键 | 操作 |
| --- | --- |
| WASD / 方向键 | 按屏幕方向移动 |
| 左键 / J | 职业普攻，鼠标在场景内时朝鼠标瞄准 |
| 右键 / K | 职业次级技能，25 精力、5 秒冷却 |
| R | 职业终极技能，45 精力、11 秒冷却 |
| 空格 | 职业位移，短暂无敌 |
| E | 与 NPC 交谈、开箱、使用城门或出口 |
| Q | 喝药，恢复 60% 最大生命 |
| T | 返回本章城镇，恢复生命和精力 |
| I / C / L / V | 行囊 / 角色 / 技能 / 任务 |
| B / N | 支线委托 / 角色与怪物图鉴 |
| Tab / M | 区域探索图 / 五章世界路线 |
| 鼠标滚轮 | 缩放相机 |
| Esc | 关闭面板或暂停、存读档、画质和音效设置 |

精力上限 100，每秒恢复 10。背包 36 格，满包时装备留在地上，可出售腾出空间。

## 三职业

| --- | --- | --- | --- | --- |
| 战士 | 顺劈斩，扇形近战 | 旋风斩，持续范围伤害 | 裂地重击，范围伤害与眩晕 | 冲锋，落点打击 |
| 法师 | 火焰弹，命中后爆炸 | 寒冰新星，冻结与减速 | 陨星坠落，延迟范围打击 | 闪烁 |

## 五座安全城镇与十五张冒险地图

每章从城镇开始，城镇中没有怪物，不会触发战斗技能。五名 NPC 分别提供：领取主线委托、25 金购买药水、付费锻造稀有装备、切换职业、免费休息恢复。死亡也返回本章城镇，损失 15% 金币并补充至少三瓶药水。

| 章节 | 城镇 | 三张冒险地图 | 最终首领 / 特殊技能 |
| --- | --- | --- | --- |
| 灰烬来信 | 余烬镇 | 余烬村外 → 遗忘墓园 → 钟楼地窖 | 欠薪守墓人：钟鸣震荡、召唤骷髅 |
| 沼泽的税单 | 青灯港 | 蘑菇渡口 → 沉没水道 → 蛙王金库 | 收税蛙王：毒潭、五重毒息 |
| 雪线上的热汤 | 雪松堡 | 风雪驿站 → 冰封矿道 → 霜心熔炉 | 冰箱骑士：环形冰牢、减速冰弹 |
| 不准下班 | 炉火城 | 焦土工坊 → 废弃流水线 → 契约焚化室 | 恶魔总监：直线火墙、狂暴双线轰击 |
| 黎明退货处 | 晨星圣所 | 破晓庭园 → 倒悬书库 → 永夜王座 | 永夜之王：换位、环形弹幕、地面封印 |

所有最终首领半血后进入强化阶段，加快施法并增强技能。地面范围技有约 1 秒预警，可用闪避规避。

冒险地图扩大为 **54 × 36** 网格，是初版 30 × 20 的 **3.24 倍面积**；城镇维持 30 × 20。地下城有十五间互相连通的房间、宽走廊与随机扩展区；地面有更多地标、营地、板车和宝箱。每图收集三枚印记并清除全部敌人，在东侧出口按 E 推进。五章通关后进入更高等级的无限周目。

## 普通怪物、精英与掉落

- 每张冒险地图有 22 / 28 / 34 名怪物，章节终图另有一名最终首领。
- 六类普通怪物：亡卒、骷髅、术士、猎犬、蜘蛛、弩手；章节使用不同名称及材质风格。术士与弩手远程攻击。
- 每图随机分配 **4 / 5 / 6 名精英**，体型更大，有光环、额外生命和特殊词缀。
- 精英词缀：烈焰地面攻击、冰霜减速弹、雷鸣散射、吸血恢复、迅捷冲刺。
- 精英必掉 **两件稀有或更高品质装备**；最终首领必掉 **三件装备，其中一件传说，其余至少史诗**。
- 普通至传说五种品质，武器、护甲、护符三个槽位；随机名称、力量和暴击。武器加攻击，护甲增加生命及减伤，武器和护符的暴击词缀生效。
- “无限装备”指持续随机生成和随深度增长的数值，不代表无限手工素材。

## 画面与面板

默认 960 × 600 渲染 3D，再以最近邻显示；轻微色阶量化、抖动与独立高清 UI。暂停菜单支持精细像素、经典像素 720 × 450、原生细节 1440 × 900 三档。

模型细节包括角色面部、盔甲铆钉、裙甲、披风、箭袋、NPC 职业工具、骷髅骨节与动物关节；建筑增加窗框、门钉、招牌、雨桶、藤蔓、市场棚、水井、铁砧及旗帜。树木有枯树、针叶树、桦木、阔叶/垂枝树等变体。火盆余烬、烟雾、环境飞雪/光点、击中特效与技能投射物使用真实 3D 粒子或动态模型。

`assets/textures` 包含 **22 套 256 × 256 表面材质（共 66 张）**，每套包含颜色、法线和粗糙度：石材、土壤、木材、织物、金属、皮革、皮肤、骨骼、屋瓦、树皮、鳞片、符文、锁子甲、刺绣、锈蚀、毛皮、甲壳、彩玻璃、大理石、羊皮纸、铜绿和苔藓。可运行 `python3 tools/make_textures.py` 重新生成（需要 Pillow，仅生成时需要）。

角色、行囊、技能、任务、对话、路线、暂停与死亡面板统一采用暗石底纹、金属饰边和凹槽；行囊有 36 格物品图标、装备槽、品质颜色、属性对比、装备/出售操作。Tab 区域探索图显示地形、已发现敌人、精英及出口。

## 0.5 模型细化与新增玩法

三职业补充锁子甲、护腕、靴带、刺绣、符文和职业配件；NPC 增加护目镜、围裙、信件与随身工具；怪物增加肋骨、獠牙、毛皮、甲壳与关节，五章首领加入独立装饰。建筑增加扶壁、彩玻璃、窗台和风化细节，树木增加根须、苔藓与菌类。模型按可动部件合并同材质网格，保留肢体动画。修正旋转部件的局部缩放，避免蜘蛛腿、梁柱等变形。

角色面板显示实时 3D 肖像；按 N 打开 15 项模型图鉴。主要面板新增统一页签，可直接切换角色、行囊、技能、任务、委托和图鉴。

- 按 B 在城镇接取、领取三类支线委托：击杀 12 名怪物、击杀 3 名精英、开启 4 个宝箱。奖励金币、稀有装备和材料，每章重置。

- 碎片、装备强化和支线进度随存档保留；祭坛与地图一起重置，临时祝福不写入存档。

## 0.6 动作与模型迭代

本轮按截图检查、调整、复查完成：胸甲改为带腰部收束的分段网格，肩甲加入重叠甲片，手部增加手掌和手指。降低金属、皮肤和毛皮法线噪声，猎犬重建口鼻、四足关节、爪、下颌与尾巴；蜘蛛使用八条独立分节腿。修复自定义网格与基础网格合并时丢失三角面的缺陷。

## 0.7 打击感与特效层

新增 `scripts/vfx_3d.gd` 战斗特效池：程序化生成的扩散环、挥砍弧、地面残留、命中光核、冰锥碎石、竖直光柱和蓄能环，外加五盏动态点光池；全部几何在代码里构建，不引入外部资源，由 `world_3d.sync` 驱动、暂停时随场景冻结。

- **法术与攻击**：火焰弹命中留下焦痕与余烬；寒冰新星带冰锥、霜面与冲击环；裂地重击双层冲击波加碎石尘团；陨星有预警光柱、收缩蓄能环和坠地爆发；旋风斩旋转刃与环形粒子；箭雨、散射、闪烁与疾退各有机尾与落点反馈。
- **投射物**：火焰弹、毒弹、冰弹和箭矢都带世界空间拖尾与光晕，火焰弹额外携带点光。
- **打击反馈**：命中触发白热光核、冲击环、爆发粒子与点光；暴击造成 75 ms 卡帧并加强震屏；敌人受击有挤压回弹和轻微后退；玩家受击同样卡帧。
- **动作**：攻击从对称 `sin` 摆动改为「蓄力 → 击出 → 收招」三段曲线；弓箭手拉弓撒放与弓弦、搭箭联动；施法时双肩后收、法杖前推，法杖顶端宝珠随蓄力变亮；战士剑刃在挥砍瞬间亮起；受击含胸后仰、倒地先跪后沉、闪避前倾收腿。
- **模型与贴图**：球体细分提到 18×9、圆柱 16 段，肢体轮廓更圆润；新增踝关节，行走时脚掌随步态滚动；`tools/make_textures.py` 改为从独立高度场计算法线（替代由颜色亮度推法线），并把环境光遮蔽烘进反照率、让凹陷处更粗糙，凹槽、砖缝与雕刻符文真正读得出凹陷。

## 0.8 小宠物系统

城镇新增第六位居民「宠物商 · 绒绒」，玩家可以在她那里花金币抽卡获取战斗伙伴；每章首领被击败后也会随机掉落一只稀有起步的伙伴（最终章必出传说）。重复抽到同一物种会自动转为「进阶 +2 级」。

- **十种伙伴**：余烬鼠、骨犬幼崽、荧光蛾、苔壳龟、霜羽鸦、熔岩史莱姆、符文石灵、幽焰狐、虚空之眼、黎明幼龙；近战与远程两类，远程伙伴发射带特效的投射物（毒粉、寒气、火焰）。

- **界面**：左侧新增伙伴状态卡（生命、攻击、间隔、复活倒数），按 `P` 打开小宠物面板查看详情、切换出战与抽卡；伙伴栏上限 10 只，满员时最弱的一只会自动让位。

## 0.10 开始界面与存档槽

启动即进入标题画面：余烬漂浮的动态背景 + 三个存档槽卡片，开始游戏与存档管理合并在同一屏。

## 0.11 三难度 · 100 级 · 暗黑2 式经验曲线

按《暗黑破坏神 2》的规则重构了等级、经验、怪物与难度：最高 **100 级**，三档难度，升级不再廉价。

- **三难度**：普通（区域 Lv.1-30）/ 噩梦（Lv.31-60）/ 地狱（Lv.61-90）。难度决定区域等级与怪物强度（噩梦怪物生命 ×1.12 / 伤害 ×1.18，地狱 ×1.30 / ×1.42），并提高金币与掉落。新建旅程时选定难度（噩梦 / 地狱需先通关前一档），难度界面按数字键 1/2/3 快速选择。
- **通关晋升**：打完第五章即标记当前难度通关并解锁下一档；胜利面板可直接「进入下一难度」，**等级、装备、宠物、成就全部保留**，章节从第一章重新开始——正是暗黑2 的难度轮回。
- **经验曲线**：升到下一级所需经验按 `120 × 等级^2.5` 增长（1 级 120 点，50 级 212 万，99 级 1170 万）。全清模拟标定的节奏：普通通关约 33 级、噩梦约 62 级、地狱约 86-90 级；100 级需要在深渊（每轮区域等级 +3）里反复轮回。
- **等级差惩罚**：怪物等级高于你时经验最多 +50%；低于你时按 `(怪物等级/角色等级)^6` 急剧衰减——80 级角色杀 60 级怪只拿到不到两成经验，回头刷低级图几乎没有收益。
- **怪物与经验挂钩**：每只怪物带自己的等级（精英 +1、首领 +3），基础经验只由怪物等级决定；怪物生命 `26 + 23×等级`（精英 ×3.2、首领 ×12），伤害 `7 + 1.8×等级`，全部随难度再放大。
- **死亡惩罚**：噩梦死亡损失本级所需经验的 5%，地狱 10%（普通无惩罚），死亡时在日志中明示。
- **经济与装备同步**：掉落、宝箱、委托、锻造、强化的价格与产出全部改按区域等级计算；装备强度 `item_power` 随区域等级成长，保证玩家伤害跟得上地狱怪物的血量。药水价格随区域上涨（15 + 3×区域等级）。
- **成就扩充**：新增「半百之躯」（50 级）、「登临百级」（100 级）、「噩梦终结」、「地狱已空」与隐藏成就「深渊常客」，共 39 项。
- **存档 v6**：记录难度与各难度通关状态，兼容读取 v1-v5 旧档（旧档默认普通难度）。
- **界面**：HUD 右上角显示难度与区域等级，经验条上方显示「Lv.X · 经验 x / y」（大数字自动缩写为万/亿）；角色面板显示等级上限、难度与区域等级；存档卡片显示难度。

## 存档与地图重置

自动保存发生在领取委托、选择职业、出城、回城、切图时；暂停菜单也可手动保存。保存职业、当前章节/地图、城镇状态、委托状态、等级、金币、药水、装备和背包，兼容旧版存档。

**当前版本回城、读档和死亡会重置该冒险地图的敌人、宝箱和未拾取物品；重新出城从当前地图入口开始。** 已拾取装备与角色成长保留。

存档 `user://embers_save.json`；macOS 默认为：
`~/Library/Application Support/Godot/app_userdata/烬下 · BELOW THE EMBERS/embers_save.json`
