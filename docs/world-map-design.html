§ 01

坐标基准

所有区域共用同一套 68×68 的格子系统。格子索引用于寻路与碰撞，世界坐标用于摆放实体。两者之间只有一个换算关系，新增任何内容时先确定格子索引，再换算成世界坐标写进配置。

常量　　CFG.MAP = 68（格）　CFG.TILE = 2（世界单位／格）　地图中心格 c = 34
格 → 世界　wX(t) = (t − 34) × 2　　　　例：t=34 → 0.0　t=51 → 34.0
世界 → 格　tX(x) = round(x ÷ 2 + 34)　　例：x=−24 → 22　x=0 → 34
可站立判定　canStand(x, z, r) — 检查 (x±r, z±r) 四角所在格是否均为可行走
朝向　　+X 向东（图版右）　+Z 向南（图版下）　相机固定俯视 3/4，偏移 (0, 27, 21) × 缩放
量值说明
地图外接±68 单位68 格 × 2 单位，边界一圈强制为墙
城镇可行走域椭圆 rx 40 / rz 30判据 (x/40)² + (z/30)² < 1.08
野外可行走域椭圆 r 58判据 (x/58)² + (z/58)² < 1.05，四角为不可达空白

§ 04

地下结构的生成规则

副本与裂隙不使用固定坐标，而是同一套房间-走廊生成器，靠随机种子区分。理解这几个参数就能预测任意一层的形态，也能据此设计"固定房间"的注入点。

房间-走廊生成器 PROCEDURAL FLOOR · SCHEMATIC
房间 0 = 入口　房间 N = 首领 / 下行门
房间（7–14 × 7–13 格） 走廊（2 格宽） 首领房 入口房（不刷怪）
种子　裂隙 seed = 0x5f3a ^ (depth × 2654435761)　　副本 seed = 0xa11ce ^ (id.length × 7919) ^ (floor × 2654435761)
房间　最多 13 间，尺寸 7–14 × 7–13 格，彼此外扩 3 格不重叠，400 次尝试
连接　相邻房间中心用 L 形 2 格宽走廊串联，另加 3 条随机回路（避免死胡同）
刷怪　房间 0 除外，每间 2 至 4+min(4,depth) 只；精英概率 9% + 1.2%×depth
怪物等级　裂隙 = round(2 + 1.7 × depth)　　副本 = 副本基准等级 + 层数 − 1
首领　裂隙每 3 层一只，按 塞克拉 → 格罗姆 → 瓦拉克 → 阿拉卡 轮换；副本固定在末层

房间本身仍由 genRooms() 生成。特殊房间是在生成后按房间序号打标签，不改生成器：
