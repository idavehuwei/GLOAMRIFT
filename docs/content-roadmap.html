§ 02

v3.1 · 把玩家留住

目标：让一局游戏能跨越关闭页面。这一版不加任何新玩法，只补基础设施——但它决定了后面所有内容有没有意义。

F1

存档与继续

2 人日 · 必做

localStorage 单槽自动存档。存的是玩家状态而非世界状态——世界是种子生成的，回来时重新生成同一份即可，这样存档体积能压在 20 KB 以内。

const SAVE_KEY = 'shadow-depths-save-v1';

function serialize() {
  return {
    v: 1, t: Date.now(),
    cls: P.cls, lvl: P.lvl, xp: P.xp, xpNext: P.xpNext, gold: P.gold,
    pts: P.pts, skPts: P.skPts, base: P.base, ranks: P.ranks, barSkills: P.barSkills,
    potHp: P.potHp, potMp: P.potMp,
    equip: P.equip, bag: P.bag,                 // 物品是纯数据对象，可直接 JSON 化
    kills: P.kills, eliteKills: P.eliteKills, killByType: P.killByType,
    cleared: P.cleared, quests: QS,
    riftDeepest: W.riftDeepest, discovered: W.discovered,
    lastArea: W.area.kind === 'town' ? 'town' : 'town'  // 一律回城，避免存半个副本
  };
}
// 触发点：升级 / 装备变更 / 交任务 / 切区域 / 每 60 秒 —— 全部走同一个 saveSoon() 节流
要处理的边界
  • 版本号不匹配时丢弃存档而不是崩溃
  • 死亡时先扣金币再存，避免"读档复活"绕开惩罚
  • 提供"重新开始"按钮，清档并回到职业选择
顺带解决
  • 多角色槽位（3 个），职业选择界面变成角色列表
  • 存档导出/导入为一段文本，方便换设备
F2

城镇服务位补齐

1.5 人日

卷宗一里预留的南侧带状区域（z ∈ [8, 24]）落三个功能点：仓库（40 格共享，跨角色）、悬赏板（每日随机任务，见 F9）、传送石碑（已探明区域快速往返，省掉走回头路）。三者都是纯 UI + 数据，无新美术依赖。

仓库 (−20, 14)悬赏板 (10, 16)传送碑 (0, 20)复用 openNPC 面板
F3

F4

套装

1.5 人日

每职业两套，2/4/6 件递进效果。套装件只从副本首领和裂隙首领掉落，给"打副本"一个独立于数值的理由。效果要改变打法而不只是加数值——比如战士的"裂地斩命中 3 个以上目标时刷新猛冲冷却"。

示例 · 战士「石桥守望」
  • 2 件：受击时 15% 概率获得 3 秒 20% 减伤
  • 4 件：旋风斩期间移动速度不再降低
  • 6 件：坚壁破碎时对周围造成已吸收伤害的 200%
示例 · 弓箭手「暮语猎手」
  • 2 件：翻滚后 2 秒内攻速 +30%
  • 4 件：穿透射击每多命中一个目标伤害 +12%
  • 6 件：箭雨范围内的敌人受到的暴击伤害 +25%
§ 03

v3.2 · 让构筑有分叉

目标：两个同职业、同等级的角色应该玩起来不一样。现在的技能系统只有"点满六个技能"一条路，天赋与技能符文把它拆成选择题。

F5

天赋树

3 人日

每职业三条线（战士：狂怒 / 壁垒 / 大地；法师：烈焰 / 冰霜 / 奥术；弓手：精准 / 陷阱 / 疾风），每线 6 个节点，10 级开放，每 2 级 1 点。节点分三类：数值（+X% 暴击伤害）、行为（火球改为穿透但伤害 −20%）、关键（每线终点，改变一个技能的机制）。关键节点互斥——一次只能激活一个，逼出取舍。

F6

技能符文

2 人日

每个技能升到 3 级解锁一个符文槽，符文改变技能形态而非数值。这是"同职业不同玩法"最直接的杠杆，而且复用现有的技能等级与面板结构。

技能符文改变
火球术裂焰命中后分裂为 3 枚小火球，总伤害不变
火球术凝滞飞行速度减半，但命中留下 3 秒燃烧地面
多重射击收束箭矢数量减半，扇形角度收窄，单箭伤害翻倍
裂地斩震荡不再击退，改为命中数每 +1 则冷却 −0.4 秒
寒冰新星凛冬范围 −30%，但对减速中的目标伤害 +80%
猛冲破阵穿过敌人后可再次冲刺一次（2 秒内）
§ 04

v3.3 · 让重复刷有变量

目标：第 20 层和第 3 层不只是数值不同。所有改动都作用在生成阶段，不改战斗核心。

F7

特殊房间

2 人日

按卷宗一 §04 的方案，在生成后给房间打标签，而不是改生成器。四种：宝库（4 宝箱 + 一队守卫）、祭坛（三选一增益，持续到离开本层）、囚笼（放出一个 NPC 随行战斗 60 秒）、陷阱厅（地刺 / 落石 / 毒雾，通过后必掉一件稀有）。每层随机 1–2 个，深度越大出现概率越高。

祭坛效果（三选一）
  • 贪婪：本层金币掉落 +150%，但你受到的伤害 +25%
  • 迅捷：移动与攻击速度 +20%，最大生命 −20%
  • 丰饶：本层怪物数量 +50%，掉落品质提升一档
实现要点
  • 新增 W.roomTags[]，在 enterRift/enterDungeon 刷怪循环前分配
  • 宝箱复用木桶的破坏逻辑，换模型与掉落表
  • 祭坛增益写进 P.buffs，切区域时清空
F8

裂隙词缀

2 人日

从第 5 层起，每层随机附带 1–2 条词缀，进层前在传送门面板上明示，玩家可以选择"换一层"（消耗少量金币重掷）。词缀既加难度也加收益——这是无限层从"数值墙"变成"策略选择"的关键。

每日悬赏

1.5 人日

悬赏板每天刷 5 条随机任务（在某区杀 N 只某类怪 / 通关某副本 / 到达裂隙第 N 层 / 不使用药水通关一层）。完成 3 条给一个奖励箱，含随机套装件或高阶符文。这是把已有内容重新组织成日常目标，不需要新玩法。

复用 QUESTS 结构按本地日期生成种子与存档同步

§ 05

v4.0 · 拓宽

前面三版都在加深现有内容，这一版才往外扩。放在最后是因为：在存档、构筑、变量都补齐之前，加更多区域只会让空洞被拉得更长。

三张新地图

北境冰湖 (Lv24)、沉船海岸 (Lv30)、断桥修道院副本 (Lv27)。配置模板与接入坐标见卷宗一 §05；新增两种阻挡样式与两套地面色板。

F12 · 3 人日

试炼场（终局）

限时波次挑战，20 波递进，每 5 波一个首领。排行榜记录本地最佳。给满级玩家一个可量化的目标，也是构筑的检验场。

F13 · 2.5 人日

第四职业 · 德鲁伊

召唤流：狼灵与藤蔓协同作战。会暴露现有 AI 只服务于"敌对单位"的假设，需要先把友方单位抽象出来——这也是未来做同伴 NPC 的地基。

F14 · 2 人日

手感与呈现打磨

受击顿帧、击杀慢镜、首领登场运镜、技能预输入队列、连击计数。工作量不大但对手感的提升往往超过一个新系统。

与美术计划的耦合

两条线基本独立，只有三处需要对齐：F4 套装需要武器与护甲的品质外观分档（美术第一期产出后才有视觉体现，功能可先上）；F7 特殊房间需要宝箱与祭坛模型（第三期）；F13 德鲁伊需要新职业骨架与两个召唤物（第二期结束后插入）。其余功能均可在方块模型下先做完并验证手感。

建议的推进节奏：功能线先行一到两个版本，美术线跟在后面替换。原因是替换模型不改变任何数值与判定，什么时候接都不会返工；而功能改动如果等美术就位再做，会一直拖着"关掉页面就没了"这个最伤留存的问题。

不做什么

被否决的方向理由
多人联机需要服务端、同步与作弊防护，成本是当前所有计划之和的数倍；单机体验尚未打磨完
开放世界无缝地图现有分区加载正好卡在浏览器内存与首屏预算的合理区间，无缝会同时压垮两者
更多职业（第五、第六个）四个职业已能覆盖近战 / 法术 / 远程 / 召唤四种范式，再加只会稀释平衡精力
付费或内购结构项目定位是可直开的浏览器单机，任何账号体系都会打断"点开就玩"
