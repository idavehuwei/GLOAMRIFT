§ 01

为什么玩家愿意打第三十遍

不是因为掉落"更好"，而是因为每一次掉落都可能不一样。三个驱动力叠加使用，缺一个这套系统就塌。

驱动力 一

完美度

同一件传奇每次掉落，词缀在区间内重掷，界面显示一个 0–100% 的完美度。你已经有「工头的量尺」了，但它是 61%。你知道存在 97% 的版本——这就够了。

驱动力 二

改变打法的特效

传奇不是"数值更大"，是"技能变形"。火球分裂成三枚、猛冲可以连续两段、翻滚期间自动射箭。玩家刷的不是装备，是一套新的玩法。

驱动力 三

条件掉落

无伤、限时、不喝药、触发隐藏阶段——每个条件提高掉落品质上限。这让重复战斗有了技术进步空间，而不只是重复。

还需要一条兜底：纯运气不能是唯一路径。每个首领掉信物，攒够可直接兑换指定专属件。运气好的第五次就拿到，运气差的第二十次靠兑换保底——两条路都通，玩家不会因为连续二十次空手而弃坑。

完美度：同一件装备的一万种版本

每件专属传奇有 3–5 条固定词缀，每条给出区间。掉落时逐条在区间内取值，完美度 = 各条实际值在区间中的位置的加权平均。这是最便宜也最有效的重复刷取驱动——不需要新内容，只需要一个百分比。

function rollUnique(def, ilvl, quality) {
  // quality 0–1，由难度与挑战条件抬高下限（见下表）
  const lo = quality * 0.55;              // 挑战条件把"最差能掉到多烂"抬起来
  const rolls = def.affixes.map(a => {
    const t = lo + Math.random() * (1 - lo);   // 0–1 的位置
    return { ...a, v: Math.round(a.min + (a.max - a.min) * t), t };
  });
  const perfect = Math.round(
    rolls.reduce((s, r, i) => s + r.t * (def.affixes[i].w || 1), 0) /
    def.affixes.reduce((s, a) => s + (a.w || 1), 0) * 100);
  return { ...def, ilvl, affixes: rolls, perfect };
}

回响版：噩梦难度专属变体，多一条强力词缀，同时多一条负面词缀（例如"最大生命 −25%"）。它不是纯粹的升级，是一个构筑上的赌注——这类物品在 ARPG 里最容易成为讨论焦点。

保底

两条保底并行：幸运值让神器概率随空手次数递增（每次未出 +2.5%，出了归零，第 20 次强制必出）；
信物让最坏情况也有确定终点（每次 2–4 枚，40 枚兑换，约 15–20 次必得指定件）。 
// 幸运值：存在存档里，按首领分别计
P.luck = { valak: 0, singer: 0, grey: 0, assembly: 0, kor: 0 };

function bossDrop(bossId, ilvl, quality) {
  const pool = UNIQUES[bossId];
  const out = [];
  // 保底 1 件
  out.push(rollUnique(pick(pool.legendary), ilvl, quality));
  if (Math.random() < 0.22) out.push(rollUnique(pick(pool.legendary), ilvl, quality));
  if (Math.random() < 0.04) out.push(rollUnique(pick(pool.legendary), ilvl, quality));
  // 神器（地狱以上）：基础 4% + 幸运值
  if (W.diff !== 'normal') {
    const p = 0.04 + P.luck[bossId] * 0.025;
    if (Math.random() < p || P.luck[bossId] >= 19) {
      out.push(rollUnique(pool.artifact, ilvl, Math.max(quality, .4)));
      P.luck[bossId] = 0;
    } else P.luck[bossId]++;
  }
  P.tokens[bossId] = (P.tokens[bossId] || 0) + 2 + Math.floor(Math.random() * 3);
  return out;
}

钉完之后第三年，雨又开始少了。众议要钉第二根。瓦拉克拒绝了，理由他只说了半句："我听见他喊了。"没有人问他听见了什么。他们把他封进要塞的墙里，用的是他自己教出来的手艺——他能听出砌到第几层。

战场里可读的东西

要塞三层是他的工棚。墙上刻着十九道正字，每一道旁边压着一件小物：一枚纽扣、一撮头发、一枚顶针、一只小孩的木刻。这是他拦下的十九个人留下的。玩家可以逐个查看，每查看一个出现一行字（"第七个。她说她是自愿的。她带着顶针。"）。全部查看后触发隐藏阶段的第一个条件。

阶段 一
工头

常规近战 + 投掷。他用的是砌墙的工具，动作是干活的动作，不是打斗的动作。

阶段 二
砌墙

他开始在战场上砌墙——用石块把可活动区域一段段封死。玩家必须打碎墙才能保持机动，但每打碎一堵，他获得一层"熟练"（攻速提升）。贪速度还是保空间，是这个阶段的核心取舍。

半血

你以为你是来杀我的。你是来量尺寸的。

阶段 三

十九个被他拦下的人的虚影出现在墙上刻痕的位置，一个接一个走出来。它们不攻击你，它们走向瓦拉克，被他一个个按回去。每按回一个，他回血 4%。玩家要抢在他按回去之前"接住"虚影（走到它身边）。

倒下

（他没有消散。他坐了下来。）行。你赢了。
那你替我问她一句：第八根，她打算用谁？

无名唱者

湖底钟窖 · LV 33 / 68 / 88
四十七个人的合声。它没有名字，因为它是复数。
生前身份
断桥修道院唱诗班 · 四十七人

砸钟的人是天黑之后到的。修道院的规矩是"唱起来就不能停"，所以他们没停。钟被撬起来推向湖里的时候，四十七个人跟着钟走——不是被推下去的，是跟着走的，因为钟在动，唱的对象就在钟上。

他们唱到一半沉进水里。水下没有声音，但共鸣还在传。三百年过去，他们还差最后一段没唱完。

战场里可读的东西

钟窖四壁刻着乐谱，是那段没唱完的曲子。玩家可以站到不同位置"听"到不同声部。整场战斗有节拍——boss 的攻击严格踩在拍子上，熟悉之后可以靠节奏预判躲避。这是全篇唯一一个"可以被听懂"的首领。

阶段 一
四十七个声部

它有 47 层护盾，每层对应一个声部。玩家造成伤害会剥离声部，每剥离一层，合声就少一个人，音色变薄。

阶段 二
和声攻击

声波以圆环形式从中心扩散，节奏严格对应四拍。走位窗口就在换气的半拍上。此阶段不看反应速度，看有没有听。

阶段 三
最后一个声部

只剩一个走调的、很轻的孩子的声音。它的伤害降到极低，但它开始跑——在钟窖里躲，边躲边唱。玩家要在 60 秒内追上它。

剩最后一个声部时

（一个八岁孩子的声音，高半度，走调）
……还没唱完呢。

隐藏 四
唱完 触发：阶段三不追击，站在钟下不动直到 60 秒结束

你不追它，它就把那一段唱完了。唱完之后，四十七个声部一起回来——不是攻击，是最后一次合唱。战斗以你不出手的方式结束，视为完美击杀，掉落品质拉满。

唱完之后

（四十七个声音一起）谢谢。

（然后水面上浮起四十七盏灯，一盏比一盏小。最小的那盏在最后。）

格雷·维尔德

生前身份

「回声号」。他妻子和儿子在上面

他一辈子在做同一件事：证明父亲没有白死。所以当第一座镇子的人算出"雨只灵三年"、准备把真相带走时，他不能让这话传出去——那等于说他父亲是白死的，是被骗的，是个笑话。

战场里可读的东西

战场是船腹内部，会随潮水倾斜——地面倾角实时变化，影响走位与投射物轨迹。舱壁上刻着十一条船名，最后一个名字被人用凿子反复刮过，刮得很深，但还认得出来。

阶段 一
凿

他还在凿那块板，不理你。你打他，他才回手，回手之后立刻转回去继续凿。他真正的目标不是你——这是设定二最直接的一次演示。

开场

你数过钉子。数过船没有？

阶段 二
十一条

他开始报船名，每报一个名字，船腹就渗一次水，水位上涨一格。水位越高，玩家移速越低，而他不受影响。十一个名字报完，舱室灌满，进入下一阶段。

报到第十条

（他停住了。）第十一条。

他从不主动攻击你。他在挣脱。屏幕上的"血条"实际是挣脱进度条，会自己往上涨；玩家造成伤害会把它压下去。进度涨满 = 桥墩崩塌 = 失败。

战斗中他会问你三个问题。回答不影响胜负，但会记录在存档里，影响最终演出的细节。这是全篇唯一一场你在跟一个讲道理的人打架。
