## 标题页崩溃修复（set_margin_all）
- **报错**：`Invalid call. Nonexistent function 'set_margin_all' in base 'StyleBoxTexture'`（Godot 对 StyleBox 调用了 Godot 3 旧方法名）。

- **修复**：两处 `set_margin_all` → `set_content_margin_all`（`frame_plate()` 24 / `socket_style()` 8）。
- **验证**：headless `--script` 直接 `load("res://scripts/UiKit.gd").new()` 调 `frame_plate()`/`socket_style()`/`plate()`，三个均返回有效 StyleBox，无报错。全项目 `set_margin` 族旧方法名已清零。
- **迁移陷阱可复用**：Godot 3→4 的 StyleBox 方法 `set_margin_all/get_margin/set_default_margin` 等均已改名 `set_content_margin_all` 等，扫描旧工程时优先 grep 这些。
